# SHIELD ALPHA SUPREME AI — v1.0

لوحة قيادة ورقية. ليست نتيجة حساب، ولا تتصل بـ ADSS أو MetaTrader 5، ولا ترسل أوامر.

التداول الحقيقي مقفل داخل الكود. لا تُعرض أرباح. الأرباح غير مضمونة، وعقود الفروقات قد تخسر بسرعة.

## فتح اللوحة

- المصدر: https://github.com/brgalain6/shield-alpha-supreme
- الصفحة: https://cdn.jsdelivr.net/gh/brgalain6/shield-alpha-supreme@main/index.html

قد يتأخر رابط الصفحة دقائق بعد أول رفع. لا توجد كلمات مرور في هذا المستودع.

## مادا يُنفّذ

- واجهة عربية RTL مع تبديل إنجليزي.
- حالة الوكلاء، وخط سير القرار، وبطاقات مرفوضة.
- فاحص حجم: 0.25% للصفقة. إن زادت خسارة أصغر عقد على هذا السقف تُرفض الصفقة.
- إيقاف طارئ وسجل محلي في المتصفح فقط.

## مادا لا يُنفّذ

- لا ربط MT5، ولا تنفيذ، ولا نموذج مُدرّب، ولا اختبار تاريخي.
- ملفات `engine/` و `mql5/` و `sql/` مسودات لم تُشغّل على حساب وسيط.
